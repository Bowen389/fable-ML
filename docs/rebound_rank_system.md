# 独立熊市反弹龙头排序系统 v1

研究目标：只用当日及以前的量价与市场状态，筛选熊市反弹潜力商品，并检查人工指定龙头是否在启动前后进入全池前10/前30。当前是研究环境，尚无经过验证的正式买入系统，不修改现行每日评分。

## 执行

GitHub Actions 运行 `Independent rebound leader ranking`；本地安装 pandas==2.2.3、numpy==2.3.5、scikit-learn==1.8.0、joblib 后运行：

```bash
python -m unittest -v test_bear_rebound.py test_rebound_rank.py
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -u rebound_rank_research.py
```

复用 `research_cache` 已保存的原始历史，无缓存的商品通过公开端点补取。缓存数据可能滞后，报告以asof和逐商品覆盖为准。运行不改生产分数，也不发真实订单。

## 两种排序

- 固定量价先验：前期价格稳定代理、均匀放量、回踩承接代理、相对市场强度各25%，加风险扣分。这是对照，不宣称已验证权重。
- 收益模型：显式白名单24项特征，用HGB回归预测未来14日净收益加0.3倍收盘最大不利变化。两个复杂度仅按校准段表现选择；名称、ID、人工案例身份及未来标签不输入模型。

模型按2026年季度起点扩展训练；校准段120日；训练标签必须在校准起点前完成、校准标签在预测窗口起点前完成。完整15日结果要求逐日真实价格及正成交量，不补价。每季训练冻结后预测该季；当前研究榜重新拟合时也只用当时已成熟标签。

这属于时间隔离的历史滚动诊断。人工已公开2026年案例，研究者也看过旧模型表现，因此不能将本轮称为完全未见市场事件；最终仍需冻结后前瞻观察。

## 成本与标签

买入费用0、卖出费用1%、滑点0。净收益=卖出价/买入价×0.99−1。信号次日收盘代理入场，之后7/14自然日收盘退出。日K价格不是保证可成交报价。

未来7日净收益为正且当日可评估池前30，仅用作事后龙头标签。报告同时给出前10/前30的龙头召回、净收益、胜率、平均收盘不利变动与同环境全池基准。排名在全池计算，分环境时不重新编号。每日候选重叠，因此商品日结果不能冒充独立交易或资金组合收益。

## 交付文件

位于 `output/rebound_rank/`：

- `report.md`：各季度、市场状态及排序方法比较。
- `validation.json`：训练和校准边界、选参记录、覆盖缺口、指标及费用。
- `case_rankings.csv`：31个案例在事件−7/−3/0/+3/+7日的名次及后续收益，缺失也保留。
- `historical_rankings.csv.gz`：每日全池排序和事后标签，供复核误报。
- `current_candidates.csv`：当前研究候选及量价分项；参考分只映射当日名次，不是概率。
- `research_model.joblib`：研究模型快照。

## 是否替换生产系统

本版本不会自动替换。需要先确认指定案例覆盖与提前排名、同期失败商品的误报、未参与调参时段的扣费收益与回撤，并完成独立事件/前瞻验证。仅让点名赢家排名靠前不足以通过。

一代略磨24款现有精确ID覆盖22款；树篱迷宫和潘多拉之盒略磨缺失，不用久经替代。枪皮目前只覆盖已登记FN版本。历史求购、会员身份/档位/真实成本缺失；价格和成交量只能提供代理。悠悠价格与全平台成交量分开，Whale仅辅助。

# 独立大盘与后排门控

主候选只取全池Top3/Top5，先排名再过滤、不补位、不要求必须开仓。已有40/20/40开发评分和生产公式均不修改。

大盘许可：全池3日涨幅中位数超过7日涨幅中位数的3/7，且站上MA30比例较3天前不下降。允许仍负收益的跌速改善，不强制7日中位数>0。

后排许可：同板块评分第6至20名且全池名次>5，至少3件可观察，其中至少2件且占比至少25%满足：7日涨幅≤15%、3日相对7日跌速改善、量比0.8至2.5、价格≥MA10的98%。仅量价蓄势代理，不能确认资金或未来接力。

不限、大盘、后排、两者同时满足四种门控，分别结合Top3/5、4入场和3退出，共96方案。本轮固定阈值，不据历史最佳值自动替换生产规则。每商品独立冷却16天。卖出1%、无滑点；全部信号次日收盘执行，数据不足不计零收益。

输出output/rebound_gates：report.md、validation.json、current_candidates.csv（含大盘许可、后排数量/占比、开仓/拒绝理由）、trades.csv.gz。所有结果属于已见历史上的开发比较，逐笔收益非账户收益。悠悠价格、全平台成交量。

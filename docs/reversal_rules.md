# 近期低点后的品类反弹研究

本次按用户指定的2026-02-09/10、05-26至31、08-22附近案例设计，不能将这些日期作为独立验证。

新增RB1至RB5：手套、AK、M4A4、USP和格洛克分别统计。条件要求同类合格报价至少8个、当日上涨占比至少55%、当日涨幅中位至少0.5%；单品距60日高至少跌10%，30日最低收盘价距今1至10天，当日上涨1%至20%，7日涨幅不低于-3%，7日最低价反弹3%至30%，站上MA7。没有日期白名单、单品白名单或MA90转多要求。

强度分为同类1日分位×25%＋3日分位×35%＋7日分位×40%。龙头候选额外要求强度≥70分、3日及7日上涨、7日跑赢同类中位。不使用未来数据，不声称流动性/成交额龙头，也不保证此后继续上涨。

新模块90日到期样本不足30条为watch；其余沿用原健康闸门，不允许龙头标签覆盖probation或disabled。单品排名先按强度分，再按可用ML分位。同一饰品跨规则登记仍去重，持仓占用仍有效。

扫描报告另列龙头观察表和output/leader_watch_latest.csv，未通过健康闸门的候选明确标为未通过。

第一轮回放的新模块在全部指定日均无健康闸门放行。全历史设计样本14日中位净收益为-7%至-12.4%，没有证明新增买点模块有效。因此此次作为研究分支提交，不直接替换main部署。详见output/reversal_replay_2026.md。

复现：python tools/replay_reversals.py；测试：python -m pytest tests -q。回放不发通知，不修改信号日志，不更新规则状态。

归档OHLC没有历史成交量、价差、挂单深度；不实现止盈止损或账户仓位分配。固定14日模拟持有与真实择机卖出可能显著不同。

补查5月24—31日后，新增先于品类转强的独立观察标签：同类有效报价≥8、当日涨幅≥3%、当日强度前15%、3日强度前40%、7日强度前50%、站上MA7。没有要求品类普涨、7日收益转正或30日低点近期出现。

格洛克核子花园崭新5月26日满足早期观察；当天上涨27%，同类中位仍下跌4.1%。合纵5月27日开始明显反弹、28日旧确认龙头标签成立；USP次时代5月27日上涨14%，与同类中位相当，不能仅凭上涨视为同类龙头。详见output/may_early_leaders_2026.md，复现命令python tools/replay_may_leaders.py。

# 30元以上单品：7日目标重设计

这是一套重新定义目标的研究算法，尚未接入自动买点或替换main。

## 标签

信号日t，t+1真实日K收盘模拟入场，t+8退出；第二段t+8重新入场，t+15退出。每段分别扣现有2.5%手续费及买卖各0.5%滑点。

仅研究信号日价格严格大于30元、报价合格且flat_14≤0.5的饰品。T1为第一段净收益同日前30且盈利（同分按名称升序）。T0为T1且第二段净收益≥5%。阈值是研究约定，不是用户给定的精确数值；报告同时展示第二段0/3/5/10%的敏感性。

T1包含T0。若展示互斥等级，T0优先，剩余T1归T1。未来收益只用于训练标签与事后检验，不能当作买入当天已知的龙头身份。

## 因果候选规则

实际候选每天最多30个。按0.6×当天T1浅树评分百分位＋0.4×当天T0浅树评分百分位排序，同分按peer_rs7降序、名称升序；取前30。T0潜力候选为这30个中达到T0训练阈值的子集，名单合计不会超过30。事后真实涨幅Top30只用于标签，绝不用于候选排序。

浅树只使用2—4月且完整15日标签在5月1日前到期的样本；最大深度4，每叶至少300条。候选阈值按训练目标覆盖率至少95%设置。条件和阈值保存于state/seven_day_research.json，完整展开见output/seven_day_research_2026.md。

双结构条件：①距60日高点回撤至少30%，距14日低点反弹至少3%；或②近30日涨幅非负、价格不低于MA90、距14日低点反弹至少3%。没有当天上涨、品类普涨、必须近30日最深低点等硬性要求。它受已查看指定案例启发，不能声称独立验证。

双结构只保留作研究对照，不再通过取并集扩大最终候选。条件只用当日和过去数据；不含日期或单品白名单。增强树作为相同时间划分的对照，不根据验证结果反复调参。

## 验证与使用限制

训练、5—6月验证、7月以后检验按时间分开；训练和验证段在边界前留足15日标签成熟期。历史目标日已经参与讨论和设计，后段不是从未查看的独立测试。不能将宽覆盖率当成胜率。

该轮候选中位净收益仍为负，尚未证明可用的盈利买入规则。因此保留research_only，不改变原健康状态、信号日志或通知。应同时查看覆盖率、候选占比、命中率和净收益，不能为覆盖全部上涨单品而忽略误选。

复现：pip install -r requirements-research.txt；python tools/research_seven_day.py。代码只生成研究标签、规则和报告，不下单、不发通知。可选本地特征缓存存在时使用当前归档快照；需重建数据时移除缓存。

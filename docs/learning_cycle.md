# 学习与验证周期

- 每日：更新数据和固定评分；现有发布器保留按日期、版本不可覆盖的评分快照。
- 每周日23:30（北京时间）：检查按时留存快照的Top3／Top5，统计7／14自然日后的净收益、胜率、覆盖率及全池描述对照。数据未成熟不报零收益；重叠观察不冒充组合回测。
- 每月1日23:30：沿用已有研究程序，在独立工作目录运行环境中重训和搜索；候选与旧版验证清单一起保存为Actions产物90天。不会发布候选评分到日常报告，不会改现行参数。
- 发生完整反弹后，可手动运行学习工作流并勾选retrain，不自动用未经验证的反弹结束阈值触发。

新参数替换条件：同一未参与调参时段的旧版与新版对照、最近90日、三个窗口稳定性、Top3／Top5前瞻证据。月度程序保留原研究的验证，不把新旧不同测试日期的指标直接比较为改善；目前没有自动晋升器，证据不足保持旧版。重训成功本身不代表验证成功。

周报：`output/learning_review.md`；逐项结果：`output/learning_review.json`。月度候选见工作流同次运行的`learning-cycle-<run id>`产物，包括baseline、retrained和禁止晋升清单。悠悠价格与全平台成交量口径仍分开；卖出费1%，不考虑滑点。

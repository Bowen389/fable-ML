# 修复日冻结Top3/5，等待后续入场

昨日门控研究显示大盘过滤减少部分亏损，但后排硬门槛未稳定改善。持续要求回踩当日全池排名前三/前五会错过先强再洗的形态，本轮独立比较入选时点与买入时点。

无有效观察期且大盘许可时，冻结当日全池Top3或Top5，观察10自然日；不补位。期满后只有大盘许可才新建。观察商品后续不必继续排名前三/前五。

三类入场：冻结当日；观察期后续放量（rv≥1.2且r1>0、距冻结价涨幅≤10%）；先发生2%至12%回撤和rv≤1，再于后一天回升r1>0且守MA10的98%、回撤不超过12%。每类每个观察期只触发一次。全平台量比不代表悠悠独立成交量。

所有新信号必须大盘许可、数据满足、板块不在衰竭或未知阶段。比较仅大盘与大盘+后排许可，两种退出固定7天或板块衰竭后次日收盘（最长14天），共24方案。每商品按16天保留冷却，信号次日收盘代理入场，费用卖出1%、买入0、无滑点。缺失不记零。

门控、权重、已知案例均是开发假设，非新独立样本或概率保证。当前生产评分不修改，不自动升级。历史缓存实际日期公开，不把运行日称为行情日。

输出output/rebound_watch/report.md、validation.json、trades.csv.gz、watch_audit.csv.gz、current_watch.csv、named_case_entries.csv。审计含入选日期和名次、当日名次、观察年龄及开仓/拒绝理由。逐笔收益不是组合收益；候选数量限制也不等于账户持仓上限。

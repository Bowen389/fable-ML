## 必须回答的研究问题

1. 从事件日前60日起逐日重放，只使用当时已经形成的数据。区分人工事件日期、算法首次触发日期、市场修复日期，检查提前量和追涨幅度。
2. 检验早期量价建仓代理、缩量洗盘、低点承接、连续温和放量、相对市场/品类强度、第一次回踩。会员档位、真实成本和买卖方向不可从公共K线直接推定。
3. 同期纳入相似价位/品类的未反弹、失败反弹、冲高回落商品，统计召回率、误报率及净收益；不只拟合七个赢家。
4. 同一批信号比较左侧止跌、首次温和放量、首次回踩三种入场；比较7/14/30日、首次反弹减仓和跟踪退出，保留平台可成交/持有约束的限制。
5. 市场状态仅依赖历史可见特征；允许熊市局部修复，不把全池7日涨幅中位数大于0设成统一硬门槛。分开报告商品触发和环境许可。
6. 这些案例已被人工点名，可用于机制分析和开发检验，不能再作为未见过的独立验证集。最终结论须来自后续或其他未参与调参的完整事件；按时间冻结参数并隔离持仓标签窗口。
7. 统一手续费2.5%、双边各0.5%滑点；分事件报告收益、最大不利波动、命中率、样本数、覆盖率。样本不足或无方案通过时明确报告。

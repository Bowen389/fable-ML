# 对齐蓄势链条的独立评分

前期参与→量价台阶→缩量洗盘→持续量能激活→支撑空间→相对同类强度。完整链条分别20/15/20/20/15/10分，单日爆量、上影抛压、短期过热最多扣30分。连续证据分不是收益概率，不能声称高分已被证明值得买入。

比较20/5/2、30/7/3、45/10/3日的前期/洗盘/激活对齐，只按当时证据选择对齐，不能查看后续收益选窗。未要求所有龙头都来自窄箱体；会员档位、真实成本和身份只是假设，不从日K确认。悠悠价格、全平台成交量。

并列三个事先固定权重（完整链条、熊市启动、提前蓄势），及使用季度开始前8日已成熟普通历史涨幅前30标签的非负权重。人工指定名单不进入特征、不加分，只回放。正则固定，不按本次最好收益自动选参数。

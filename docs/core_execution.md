# 日常核心执行清单

日常只保留5个工作流定义：
1. scan.yml：原版日K取数及规则扫描，使用现有模型。
2. process-score.yml：每日增量补齐Firepulse日K、固定过程证据分、冻结参数多因子分；默认 DAILY_INFERENCE_ONLY=1，不重训、不重新搜索参数或重复完整历史验证。
3. daily-coil.yml：上一步成功后，复用缓存计算蓄势因子，不再取数或训练。
4. unified-system.yml：按既定三个时段等待报价及日K评分就绪，输出唯一主决策报告；保留每日Whale辅助采集。移除蓄势完成后额外重复汇总的触发，时序检查仍保留。
5. check.yml：代码变更/PR的必要回归检查，不按日定时。

外部up仓库继续报价每天3次、求购每天1次；不重复求购采集。四类传统买点全扫、815件监控、求购大户排行、Whale辅助、潜力/入场/市场门控全部保留。评分公式不因这次精简修改。

## 移出日常路径
19个历史研究或旧单品工作流已移至 research/archived_workflows/，GitHub不执行该目录中的定义：
- daily-adaptive-rank 的独立每日研究排名。
- monthly-learn 的月度模型训练、规则挖掘和自动调参。
- unified-trade-guide 的早期单Glock验证及重复数据库下载。
- 其余历史形态、回测、参数研究工作流及其代码变更自动触发。

研究源码与历史报告保留，因为部分纯因子函数仍是核心评分的依赖；不是每天执行的任务。需要再次完整研究时，可在 process-score 的手动运行中显式选择 full_research；归档的独立研究定义需恢复后再运行。

## 冻结与资格
多因子日常分沿用已保存研究参数，历史验证日期单独显示。缺少冻结研究结果时明确失败，不偷偷启动搜索。过程证据分沿用公式，模型列为空，不重新拟合；本次不会升级任何实盘买入资格。新综合决策保持研究版。
本次不删除历史数据、不停止核心采集，也不修改已有推送权限。日常参数搜索组合应为0、模型训练次数应为0；这些字段在输出中可核查。

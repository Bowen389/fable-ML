# 综合决策层 decision-v1

主入口：[综合决策报告](../output/decision_latest.md)，统一总报告和原每日报告顶部也展示相同结论。底层四类买点、原版多因子、蓄势公式保持原样。

## 执行顺序
同商品精确名称/磨损连接 → 市场/板块形态 → 潜力排序 → 位置与日K触发 → 每日求购容量 → 后排接力 → 等待或研究条件满足。
保留全部815监控行；缺少评分、日K、报价或求购时保留空值和阻断原因。Whale只作辅助、不计分；用户ID不与Steam ID关联。

## 明确公式
潜力=30 build +15 tier +20 wash +15 activation +10 relative +10 clip(1-penalty/30)；因子截断0～1。来自完整已收盘日K代理，不代表真实会员身份/成本。
入场=35 clip(1-|((挂牌价-10日最低)/ATR14)-1|/3)+20 clip(1-(ATR14/收盘)/0.12)+20 min(传统家族数,2)/2+求购项。
求购项=15 clip(有效求购件数/100)+10 clip(0.5+可比厚度变化百分比/40)。变化缺失时后10分留空，上限显示90，不能重新归一化。挂单容量不是盘口价差或真实成交。
观察上限=min(MA5+0.5ATR14,20日最高)；失效参考=10日最低-0.5ATR14，不是成交保证。
潜力Top5按潜力降序，入场分仅作同分排序；研究入场Top5只选通过全部条件且潜力≥60、入场≥65的商品。

## 市场与板块
使用传统扫描中同日、历史至少300根、价格30～13000、排刀的有效样本；样本至少50。此为研究池环境代理，不是全市场指数。
3日收益中位数<-3%且弱于前3日：下跌加速关闭；3日>0且上涨广度≥50%：反弹启动，研究放行；3日中位数改善且≥-2.5%：止跌蓄势，仅研究试探；前3日>0后转弱：反弹衰竭关闭；其他弱势仅观察。没有7日收益中位数>0前提。
板块为同武器或手套家族，至少5件；左侧研究试探要求该家族3日中位数≥0。另须存在至少1件其他商品提前蓄势分≥60，代表后排观察代理，不是可靠接力预测。
报价超过6小时、求购超过1天、非昨日完整日K、破支撑、超过观察上限、无传统买点、ATR/价格>12%、可比求购厚度降幅≥20%均不放行。

## 版本资格与验证
所有权重及阈值都是透明研究设定，未经新的历史/前瞻验证，不声称最优或高胜率。所有输出 live_buy_allowed=false，不下单、不改生产评分资格。
研究条件满足仅表示可进入模拟试探观察，不能当成实盘指令。原ML列对照，避免相同量价因子重复加分。实时求购与Whale没有完整历史，不补造回测。
每天第一份完整决策冻结在 output/history/decision_日期_decision-v1.json，后续刷新不覆盖；全部最新决策写JSON/CSV。用于积累真实前瞻样本，尚无该新版本收益结果。
新研究卖出手续费1%、无滑点，原版统计独立标注。
只重用现有历史/评分/求购采集结果；代码更新不额外调用Whale或求购接口，Whale仍手动勾选或每日既定时间执行。

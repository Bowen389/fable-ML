# 独立反弹阶段研究

现有生产评分不变。固定40/20/40开发公式，比较全池Top3、Top5主要候选与Top30对照，各自使用蓄势左侧、启动初次放量、启动后回踩四种入场，与固定7日、固定14日、衰竭触发后次日退出（最多14日）三种退出，共36方案。

阶段依据当日及历史板块中位涨幅和MA10广度，最少8件；不要求全池7日收益为正。启动为连续修复前3日，首次放量要求此前3日未出现相同放量信号，回踩为过去10日出现启动放量后的缩量阴线且守MA10附近的代理，并不证明洗盘完成。固定16天逐商品冷却，先锁定信号再检查未来数据。

卖出手续费1%，买入0、无滑点。信号次日收盘入场；退出触发次日收盘执行。持有窗口缺报价或非正成交量不记零收益。信号季度归属，结果可能跨季度；当前未成熟结果保留。

这是已见历史上的开发比较，不是全新样本。逐笔商品收益非组合净值。价格悠悠、成交量全平台；不推断会员身份、成本或真实求购。覆盖变化逐日公开。无方案自动升级生产。

结果：output/rebound_phases/report.md、validation.json、sector_phases.csv.gz、feb_gloves.csv、trades.csv.gz、current_candidates.csv。
 
排名限制先于买点过滤，不足Top3/Top5时不补足名额；这里是信号研究，不代表每天强制买入或总持仓上限。缺失日补齐保留板块键，禁止跨板块产生重复合并键。

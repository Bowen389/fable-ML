# 龙头过程定义 v3：建仓迹象—洗盘—均匀放量—加速拉升

本定义按用户2026-10-20最新纠正替换“箱体突破后涨幅最高”作为主要研究目标。
已有箱体突破研究保留为对照，不代表用户认可的完整龙头模式。

## 主要研究对象

先有可观察的早期建仓迹象，随后可能出现第二层参与者进入的痕迹；
经过洗盘或承接检验后，成交量较持续、较均匀地抬升，价格仍能随后出现一轮明显加速上涨。
“均匀放量”不是每天等量，也不是单日巨量；需检验持续性、异常峰值占比及量价推进效率。

## 当时可见的过程证据

| 阶段 | 可检验信息 | 不可直接认定的事实 |
|---|---|---|
| 早期建仓代理 | 一段时间价格推进有限，成交活动持续；在售与求购的多次快照可补充验证 | 不能把横盘、低波动或库存下降单独认定为庄家吸筹 |
| 第二层跟进代理 | 相对早期出现新的成交量/价格台阶，持续多日，成本区间有所抬升；后续检验台阶是否获承接 | 没有会员记录时不能认定“中档会员”身份及其真实成本 |
| 洗盘/承接检验 | 阶段间有回撤、活动收缩、关键参考区间承接或较快收复；同样记录跌破后继续走弱的失败例 | 不能事后因为后来上涨，就把此前每次下跌都称为洗盘 |
| 均匀放量 | 近期成交量趋势、变异系数、最大单日占比、持续天数；与更早基准量及价格推进联合比较 | 稳定高量既可能是承接，也可能是派发，须比较后续结果和当时风险特征 |
| 加速拉升前候选 | 前序证据时序成立，当前仍保留可研究的价格空间，且未出现放量滞涨/供给回流等失效迹象 | 未来大涨不能用于当日打分 |

## 顺序与变体

研究多个允许时长和顺序变体，不把一个故事硬套到每个商品：
早期建仓代理 → 第二层跟进代理 → 洗盘/承接 → 均匀放量 → 加速；
也允许“早期建仓代理 → 洗盘 → 第二层跟进及均匀放量 → 加速”。
是否必须具备每段、各段间隔多长、如何确认结束，都需在训练段检验并在留出段验证。

## 事后标签和对照

- 以均匀放量阶段或其结束点作为对齐锚点，统计随后7/14/30日收益、最高涨幅、最大不利波动、达到涨幅所需时间。
- 龙头标签需同时体现后续幅度、持续性及同期相对领先；具体阈值待检验，不再把突破箱体作为必要条件。
- 严格区分“后续最高价涨幅”与可执行入场/退出后的扣费收益。
- 对照至少包含：均匀放量后滞涨、洗盘代理后破位、持续放量但不加速、单日爆量后回落。
- 对代表性成功案例的描述性分析不能冒充样本外收益或经过验证的系统。
- 市场形态作为分层研究条件，允许熊市反弹中的左侧阶段，不设全局7日涨幅转正门槛。

## 数据边界与实施状态

悠悠价格与全平台成交量分别保留来源；跨平台量不能当悠悠独立成交量。
求购与在售缺乏足够历史快照时标为缺证，不倒填。Whale仅辅助。
目前已修订研究目标与数据需求，尚未完成v3过程识别和历史回测；现有箱体研究结果不能用作v3的验证结论。

# 转强榜研究版

## 复现

从仓库根目录运行以下命令。原榜快照文件带各日原报告提交 SHA。

```sh
python research/strength_rank.py --bars data/bars/2026-10.csv.gz data/bars/2026-11.csv --pool output/decision_latest.csv --baseline research/strength_baseline.json
```

本次结果使用截至 2026-11-06 的完整 SteamDT 日 K。研究用 815 件当前监控池回看，历史入池变化未复原，可能有样本选择偏差。逐日计算只使用报告日之前、且抓取日期不晚于报告日的完整日 K。转强分用 3／5 日相对强度、上涨持续性、收盘靠近区间高点，以及过热扣分。本轮没有可核验的历史成交量和求购序列，因此未纳入量能或求购确认。

原潜力榜用当日历史报告，转强榜按同一组报告日期生成。两榜都按次日开盘参考价入场，报告日起第 8／10／14 个自然日收盘参考价退出，扣卖出费 1%，无滑点。允许重复饰品和重叠持有，每笔等权统计。最差不利变动是样本内单笔持有期最低参考价相对入场价的最差结果。结果不代表组合净值或真实成交。
